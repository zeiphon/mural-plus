Mural Plus

Web installer · version {{VERSION}} · source

Firmware for v2 Mural hardware (the FluidNC controller board, with an SD card and a small screen), with a reworked setup, live drawing controls, a diagnostics page and updates from the browser. It won't work on v1.1 boards.

Already running Mural Plus? You can update without a cable: download {{UPDATE_BIN}} from the releases page, then in Mural open the settings (the gear, top right) and choose Install an update under Firmware.

Before you start

  • Use Chrome or Edge on a computer. The installer needs Web Serial, which iOS browsers don't have.
  • Plug the ESP32 in with a USB cable that carries data. Some cables only carry power.
  • Close anything else using the port, such as the PlatformIO serial monitor in VS Code.
  • If no port shows up, install the USB driver for your board's chip: CP210x or CH340.

Install

Fresh install

Erases the board, including settings and calibration. Use this the first time, or when coming from upstream Mural.

Your browser can't flash devices. Open this page in Chrome or Edge on a computer. Flashing only works when this page is opened over https.

Update

Keeps settings, calibration and the drawing. When the installer asks, leave “Erase device” unticked.

Your browser can't flash devices. Open this page in Chrome or Edge on a computer. Flashing only works when this page is opened over https.

After installing

  1. Mural restarts. After a fresh install it has no WiFi details, so it opens its own WiFi network called Mural.
  2. Join that network from your phone or computer. A setup page should open. If it doesn't, go to http://192.168.4.1.
  3. Pick your WiFi network and enter its password. Mural then joins your network.
  4. Open http://mural.local. If that doesn't load, look up Mural's IP address in your router's list of devices.

After an update, Mural reconnects to your WiFi by itself.

If the installer can't connect

  • Hold the BOOT button on the ESP32 while the installer says it's connecting, then let go once it starts writing.
  • Try another USB cable or port.

Flashing manually

The same files are on the releases page. With esptool:

Fresh install (erases settings):

esptool.py --chip esp32 write_flash 0x0 {{FULL_BIN}}

Update (keeps settings). This also rewrites the bootloader, partition table and boot_app0.bin, so the board starts this firmware even if a browser update had switched it to the other firmware slot:

esptool.py --chip esp32 write_flash {{USB_UPDATE_ARGS}}
